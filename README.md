# Computaci-n-estad-stica-2026-2
Este espacio integra **fundamentos teóricos**, **implementaciones en Python** y **proyectos aplicados** que exploran desde la generación de variables aleatorias hasta técnicas avanzadas de inferencia y optimización estocástica.

El material está diseñado para que cada tema se aborde desde tres perspectivas: la formalización matemática, la implementación computacional y la aplicación a problemas reales.

## 📚 Contenido por carpetas

| **Carpeta** | **Contenido** |
|-------------|---------------|
| **Documentos** | Teoría completa en LaTeX: procesos de Poisson, Monte Carlo, reducción de varianza, MCMC, optimización estocástica e inferencia variacional. |
| **MCMC** | Implementaciones en Python de Metropolis-Hastings, Gibbs sampling, HMC y aplicaciones como restauración de imágenes. |
| **Monte Carlo** | Ejemplos en Python de integración numérica, estimación de π, y métodos de reducción de varianza (antitéticas, control, estratificado). |
| **Proyectos** | Propuestas de proyectos para la evaluación final, con ejemplos completos en seguros, finanzas, clustering y procesamiento de imágenes. |
| **Simulation** | Simulación en Python de procesos estocásticos: Poisson (homogéneo y no homogéneo), compuesto, movimiento browniano y modelo de Cramér-Lundberg. |
| **Stochastic Optimization** | Teoría y código en Python sobre algoritmo EM, SGD, recocido simulado y algoritmos evolutivos. |
